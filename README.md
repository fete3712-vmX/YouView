## YouView - good, live youtube video viewer ##


![GitHub release](https://img.shields.io/github/v/release/fete3712-vmX/YouView?style=flat-square)
![Website Status](https://img.shields.io/badge/status-online-brightgreen?style=flat-square)

Free to use website.
Pull requests reviewed and accepted.

Uses 3 APIs:
* Youtube oEmbed, Features: (thumbnail, title, etc.),
* Return YT Dislike, Features: (views, likes, etc.)
* Cobalt Media Engine, Features: (download video's, etc.)
